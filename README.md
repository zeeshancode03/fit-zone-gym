# Fit Zone Gym - Fitness & Workout Website

A modern and responsive fitness website built to showcase professional gym programs, expert trainers, membership pricing plans, and interactive fitness tools.

## Features

- **Modern UI/UX**: Sleek, dark-themed fitness design built with Tailwind CSS.
- **Workout Programs**: Detailed cards for Bodybuilding, CrossFit, Cardio, and MMA.
- **Expert Trainers**: Showcase professional fitness trainers.
- **Pricing & Membership**: Clear and attractive subscription tiers.
- **Fitness Calculator**: Built-in interactive calculator tools.

## Technologies Used

- **React** - Frontend JavaScript library
- **TypeScript** - For type-safe architecture
- **Tailwind CSS** - For styling and responsive design
- **Vite** - Fast frontend build tool
